## Tela de login (PHP)

O PHP precisa de servidor para rodar:

- **XAMPP:** ligue o Apache, copie esta pasta para `C:\xampp\htdocs` e abra
  `http://localhost/projetos_norteadores/tela_de_login/index.php`
- **ou**, no terminal, dentro da pasta do projeto: `php -S localhost:8000`

Os acessos (data e hora, usuário e resultado) são salvos em `tela_de_login/dados/acessos.csv`,
criado automaticamente no primeiro login. A senha não é salva.
